# Onshape Robot Dog 3D

This project is a 3D model of a robot dog created using Onshape and Parametric CAD.

The model is based on my previous Robot Dog Design, where I created the initial mechanical concept of the robot dog. In this project, I developed that concept into a 3D model using sketches and 3D features in Onshape.

## STL Files

All parts of the robot dog were exported individually in STL format and are included in this repository.
